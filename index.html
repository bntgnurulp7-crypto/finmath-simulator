Landasan Matematis Aplikasi

Aplikasi ini menggunakan model Barisan dan Deret Geometri untuk menghitung pertumbuhan nilai uang masa depan (Future Value) dengan sistem bunga majemuk bulanan:

1. Bunga Majemuk Saldo Awal:
FV₀ = PV × (1 + i)ⁿ

2. Nilai Masa Depan Anuitas (Setoran Rutin):
FV_rutin = PMT × [ ((1 + i)ⁿ - 1) / i ] × (1 + i)

3. Total Saldo Akhir:
FV_total = FV₀ + FV_rutin

Keterangan: PV = Modal Awal, PMT = Setoran Bulanan, i = Suku bunga bulanan (r/12), n = Total bulan (tahun × 12).
